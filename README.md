# Student Record Lookup

## Problem Statement

A university maintains thousands of student records identified
by unique roll numbers. The system needs to find student records
quickly during examinations.

## Proposed Solution

We use Binary Search to search sorted student records efficiently.

## Features

- Search student by roll number
- Display student details
- Binary Search
- Compare Linear Search and Binary Search
- Count search operations

## Technologies

- HTML
- CSS
- JavaScript
